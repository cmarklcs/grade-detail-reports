Grade Detail Reports

Upload the gradebook spreadsheet you downloaded from Toddle for a class. This turns it into one printable grade-detail page per student — current grade up top, every assignment score underneath — the way Veracross used to print them. Everything is parsed right here in your browser; the file never goes anywhere.

1. Upload gradebook export(s)

Select one .xlsx file per class (the file Toddle downloads, e.g. "VisualArts.xlsx"). You can add more than one if you teach multiple sections — each becomes its own set of pages. Uploaded the whole .zip Toddle gave you instead? That works too — it'll be unzipped automatically.

2. Choose students & check the details

Course name and term are read from the file — edit if you'd like them to say something different on the printed page. Pick which students to include for each class.

Preview updates below.

For one student: scroll to their page below, click Print just this page on it, then press Ctrl+P (Windows) or Cmd+P (Mac) and choose Save as PDF.

For a whole class: print one student at a time using that same button — printing everyone at once won't reliably split into separate pages.

Finding your gradebook export in Toddle

1

Open the download menu

Go to Assessments for the class. Click the ⋮ menu in the top right, then choose Download.

2

Choose what to include

Pick the grading period (e.g. Semester 1) and leave all assessment tools checked — Score, MYP Criteria, and Final remarks/comment all feed into the report. Click Download.

3

Come back here

Upload the file you just downloaded above, pick your students, and print or save as a PDF. Repeat for each class you teach.
